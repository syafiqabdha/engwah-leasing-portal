[CRIT-01] ✅ FIXED — Hardcoded credential bypass REMOVED
  The `password !== 'password' && password !== 'admin123'` bypass has been
  eliminated. Authentication now relies exclusively on bcrypt hash verification.

[CRIT-02] ✅ FIXED — JWT tokens now expire after 24 hours
  Both the /api/login and /api/setup routes now issue JWTs with { expiresIn: '24h' }.
  The email field is also encoded into the token payload (needed for QA-01 fix).

[CRIT-03] ✅ FIXED — CORS restricted to allowlisted origins
  Open wildcard CORS replaced with an origin allowlist callback.
  Default: http://localhost:5173,http://127.0.0.1:5173
  Configurable via ALLOWED_ORIGINS environment variable.

[CRIT-04] ✅ FIXED — JWT_SECRET startup guard in place
  Server now logs a FATAL error if JWT_SECRET is missing.
  Crashes immediately in NODE_ENV=production if not set.
  Fallback changed from 'secret' to 'change_this_secret_before_deploy'.
